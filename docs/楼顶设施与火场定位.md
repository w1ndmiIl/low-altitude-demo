# 楼顶起降设施与火场定位

实时模式保留地面配送站和10m架高平台，增加4处无人机楼顶待命点，以及H01楼顶待命坪和楼顶直升机救援坪。无人机楼顶站仅接纳无人机，两处直升机坪仅接纳直升机；普通大楼不自动具有直升机起降能力。设施能力是教学设定，不能作为实际建筑具有起降资质的依据。

设施选点检查屋顶轮廓、平台尺寸、邻近建筑高度和现有泊位间距，平台高度读取对应楼高。飞机在平台面待命、垂直爬升至巡航层、下降到平台面后服务，任务完成后返场。平台继续执行物理占用与场站资源管制。起飞前检查完整爬升通道，爬升期间水平航段避让整个已保留通道，避免爬升机与巡航机相互等待。

使用左侧画面上方“观察起降设施”可定位每处设施。蓝色楼顶标记供无人机，橙色H标记供直升机。实时运营导出保留location、buildingId、buildingName、elevation、radius与accepts。

原实时火场航点位于火焰旁约100m，且火场轮廓中心经过栅格取整，与建筑显示存在偏差。新版从建筑轮廓内部选取可达的整数栅格点，火焰、任务航点和悬停点共用这一水平坐标；消防机下降至屋顶上方25m，侦察完成后再开始模拟投放。青色悬停环与连线显示作业高度，投放连线结束于同一火场。火场为课程事件，作业高度和灭火强度不代表真实飞控或消防能力。8机固定算法实验保持原设定。
