# 标准流程演示

默认选择“自动演示”，点击“开始自动演示”即可。也可直接打开 `demo/index.html?autoplay=1` 自动启动。完整离线包与源码Demo采用同一流程，无需录像。

| 环节 | 自动执行与观察 |
|---|---|
| 日常运营 | 观察20秒，看到日常航班进入巡航；应急预留机保持待命 |
| 应急派单 | 发布2人转运，依次展示入队、候选筛选、代价比较与派单记录，入队3秒、筛选3秒、比价4秒、结果3秒，共13秒；背景机队不停 |
| 优先通行 | 观察转运起飞或已经进入的航段，不回退模型；有资源和预测冲突才等待或让行 |
| 消防加入 | 向同一时间线发布火情，其他日常业务继续 |
| 跨江协同 | 空中跨江到江北起降场；江北车辆到站等货，交接8秒后继续配送，需求点收到物资才完成 |
| 运营回顾 | 显示真实完成状态；结束后保留现场并继续日常运营 |

启动会重置为20架混合机队，日常观察为8倍速，派单讲解段为1倍速，转运和消防执行为16倍速，跨江交接为32倍速，避免解释还没看完，转运就已经完成。演示只有最初重置一次，各环节共用机队和仿真时钟。派单解释固定在实际决策时刻，航空器仍在执行，因此实时位置和历史候选分数可能不同。

“暂停演示”同时冻结流程和城市，“继续演示”恢复。切到其他标签页会自动暂停，返回后点击继续。退出按钮或Esc暂停城市并恢复普通控制；重播从初始场景开始。计时按实际观察时间，不受8倍仿真速度加速；暂停期间不计时。当前目标约90秒：各片段预算合计88秒，并设置90秒总上限。暂停时间不计入预算。

转运和消防各观察10秒，跨江交接28秒，回顾7秒。执行段按真实条件推进，达到阶段或总时限时按当前状态收尾，未完成的任务继续在城市中运行。顶部显示本段剩余观察秒数。超过上限仍未完成时保留未完成记录，不把自动进入下一环节当成业务成功；结果回顾按当前事件状态计数。人员转运段看到进入巡航，也不等于人员已经送达。

## 持续任务与优先级

- 物流、巡逻、巡检、送样、补给、客运按任务循环补充；上一轮结束并冷却后才续发，每个循环最多一项未完成需求。
- 任务层按优先级与抢占资格派单；场站和走廊按优先级排队，已有持有者正常释放资源。
- 局部让行检查任务优先级、5秒预测航段和高度间隔。同级按创建时间、编号稳定排序；无冲突航空器继续运行。
- 仅在当前地点可安全等待时让行。资源容量、物理泊位、起降扫掠与返航安全仍分别检查。

## 手动讲解

“连续讲解”用下一步切换重点，城市持续运行；“逐步定格”在讲解和阶段完成后冻结全场，适合细讲。自动演示隐藏下一步按钮，保留暂停、退出和重播。

固定8机实验与当前20机实时流程分别报告。第7页是0秒历史决策，调度队列和风险路径对照也来自固定场景；自动流程不要求重复历史分数或资源快照时刻。设备慢时可退出、切2D，或按课件截图继续讲解。

## 当前跨江业务分工

飞机只承担江南到江北起降场的空运段。接驳车从江北出发，沿江北实际路网到起降场接驳区等货；空中服务与车辆到位后装载交接8秒，再由同一辆车沿江北路网送往医疗需求点（仿真）。车辆不经过隧道或跨江桥梁。到站、交接与最终送达分别记录，未送达不能记为任务完成。

当前90秒演示预算保持不变，到时只回顾真实状态，未完成任务继续运行。原固定8机/20机统计仍保留旧配置，不能拿新接驳用时替换原对照数据。
