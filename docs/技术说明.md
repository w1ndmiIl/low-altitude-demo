# 技术说明：钱江世纪城地图、交通、规划与安全

计算机课程主线见 [调度算法与实验分析](调度算法与实验分析.md)：包括三策略伪代码、实际代价与预算、检查点、复杂度、诊断与消融。当前汇报采用16页技术版本。

## 动机与低空经济联系

以城市低空配送为任务，在公开街区几何中比较航程与运行风险，并验证鸟群、链路异常和交通变化后的行为。低空应用涉及航空器、运行服务、基础设施和安全保障，配送路线只是其中一个功能环节。背景参考 [中国民航局 2026-05-27](https://www.caac.gov.cn/PHONE/XWZX/MHYW/202605/t20260527_230925.html)。

## 地理数据与来源分层

江南区域提供782栋轮廓，江北追加40栋抽样，合计822栋和945条道路记录，其中56段带道路隧道标记。钱塘江水域补充自 OSM relation 8227206。原始 XML、转换脚本、适配 JS 和来源哈希均随源程序打包，演示不需要地图服务账号。

建筑高度中 550 个取自 height 标签，272 个按楼层×3.3 m 或类别默认值补充。标签属于社区地图属性，不是本组实测，也不保证始终正确。平面位置按原点 (120.244, 30.239) 以局部等距近似投影为米，x 向东、z 向南。模型保留每栋楼的 heightSource。

三维楼宇按公开轮廓挤出，幕墙纹理由程序生成。道路中心线、连接节点和名称沿用公开数据。博奥隧道连接位置核对了 [杭州市人民政府命名批复](https://www.hangzhou.gov.cn/art/2021/11/12/art_1229063387_1804264.html)。地下深度 -18 m、坡度、交通需求与信号相位是仿真参数，不是工程测绘成果。许可见 data/LICENSE.md。

## 航域与高度障碍

活动航域为 256×144 格，每格 25 m，合计 6400×3600 m。固定巡航高度 120 m，运动学速度 12 m/s。模型从巡航平面开始，不模拟垂直起降或姿态。

楼顶高度加 10 m 裕量后达到巡航平面的建筑进入占据图。栅格化采用多边形和格子相交判断，包括轮廓顶点、格子角点和交叉边，避免小于一个格子的细高楼被漏掉。较矮建筑允许从上方通过。规划占据再外扩一格，禁止对角穿角，水平连续安全半径为 1.6 m。该规划是固定高度的二维方法，不是完整三维规划。

## 风险感知 A*

沿用 [Hart, Nilsson & Raphael, 1968](https://ai.stanford.edu/~nilsson/OnlinePubs-Nils/PublishedPapers/astar.pdf) 的搜索框架，边代价如下：

`c(u,v) = d(u,v) × [1 + λg × (Rg(u)+Rg(v))/2 + λc × (Rc(u)+Rc(v))/2]`

`f(n)=g(n)+h(n)`，`h=max(dx,dy)+(√2−1)min(dx,dy)`。

d 用格单位；Rg 是人口/地面交通风险代理值，Rc 是通信弱覆盖代理值，范围 [0,1]。默认 λg=3、λc=2。权重均为零时得到距离基线。所有权重非负，使边代价不低于几何长度，octile 仍为一致下界。固定图上可求最小加权代价，但不宣称连续接入和动态环境全局最优。

固定人口与通信区域用椭圆高斯场合成。在交通场景中，地面车辆位置和低速排队额外叠加人口风险，3 s 更新快照。风险图不是实测人口密度或无线覆盖。

## 路网交通与隧道分层

96 辆车沿道路节点构成的有向边行驶，单向标签决定连接方向，车距约束限制前车追近，模拟信号控制路口通行。交通初始需求与分流选择固定，仿真不接入实际路况。

隧道沿完整路段的累计长度设置下降/上升坡段，渲染采样与车辆深度使用同一函数，避免每个节点接缝车辆突然浮上地面。地表常规模式遮蔽地下车辆，剖视可看地下通行。入口封闭后，已有地下车辆继续驶出，准备进入的车辆排队。

地下深度超过 1 m 的车辆不直接叠加地面风险。地面入口排队仍会增加代理风险。这是本项目的分层建模改进。它不意味着地下交通没有运营风险，仅表示不能把地下车辆直接当作地表人群。

## 鸟群、动态冲突与天气

鸟群挑战在 5 s 注入三只模拟鸟，10 s 注入 10 s 阵风，14 s 加入临时禁飞区。鸟的轨迹是理想已知的线段往返模型，不是实际识别/学习的轨迹。90 m 半径内进行感知，预测未来 2.2 s，并把预测占据用于重新规划。预测仍冲突时先等待。重规划冷却为 0.8 s。

每个 ≤0.05 s 的运动步同时检查建筑矩形相交和两物体连续相对运动最小距离。若 r=a0−b0、v=(a1−a0)−(b1−b0)，极小距离位置为 τ=clamp(−r·v/(v·v),0,1)。这涵盖小步内的线性运动，不能保证任意未知轨迹下绝对安全。

阵风模型把推进速度乘 0.6，并叠加简化水平漂移，10 s 后恢复。它不是气象场或空气动力学模型。图形中的无人机和鸟放大以方便观察，安全检查使用配置中的模型半径。

## 心跳与安全决策

每 0.5 s 发送心跳，单向延迟为 80+450×Rc ms，丢包概率为 0.02+0.28×Rc。固定伪随机种子保证重复试验。质量百分比是指示量，不是 RSSI/SINR。

| 触发 | 决策 |
|---|---|
| 最后收到心跳超时 1.5 s | 悬停 |
| 超时 4 s 或电量 ≤20% | 返航并锁定任务 |
| 导航异常 | 停止水平运动，6 s 恢复后重规划 |
| 电量耗尽 | 停止水平运动，记录紧急降落 |
| 初始无航路 / 途中无航路 | 拒绝执行 / 等待重试 |

返航假设机载规划、导航独立于心跳连接运行。导航异常期间真值仍用于仿真安全监测，未模拟真实惯导漂移。电池消耗为 0.08×时间(s)+0.018×航程(m) 个百分点，是教学线性模型；固定 20% 阈值没有用真实返航能耗估计，不能保证任意任务均可回来。

## 指标与实验

| 指标 | 单位与定义 |
|---|---|
| 航程 | 连续移动距离之和，m |
| 时间 | 模拟秒数，含等待，与播放墙钟时间不同 |
| 人口 / 通信暴露 | ∫风险值 dt，代理风险秒，不是事故概率 |
| 净距 | 到占据表面/边界减自身安全半径，移动物体再减其半径 |
| 重规划 | 初始搜索以外的规划次数，可区分预测触发 |
| 碰撞 | 发生占据/安全间隔失守后停止仿真并记录失败 |
| 配送 / 返航 | 分别统计终态，返航与拒绝执行不算成功配送 |

当前 187 次实验全部采用钱江世纪城环境。7 场景×2 算法×10 链路种子为 140 次，4 组静态代价消融×10 种子为 40 次，权重扫描为 7 次。随机种子只改变链路丢包，地图、风险参数和车流初始需求保持一致。

默认静态比较：距离方案 2173.83 m，完整风险方案 2437.44 m；人口代理暴露 45.414 与 7.714 s。航程增加 12.1%，人口代理暴露下降 83.0%。完整数据及标准差见 results/。

当前地图中“完整代价”和“仅人口风险”的路径相同，未测出通信项额外收益。不能将它写成两个代价项都产生独立增益，也不能从一个地图推论通信代价永远无效。

## 难点与处理

| 难点 | 处理 |
|---|---|
| 数据标签缺失、来源混淆 | 保留 heightSource、原始 XML、转换脚本与源哈希 |
| 楼宇比网格小 | 多边形与格子相交而非只检测中心点 |
| 地下车辆浮到每个路口 | 深度沿完整道路累计距离连续计算 |
| 连续位置接入离散路径 | 接入线段先检查，保持当前位置，避免瞬移 |
| 交通风险更新使基线也抖动 | 距离基线不因纯风险变化重新规划 |
| 快速播放漏掉动态交叉 | 固定步进并检查整个相对运动段 |
| 恢复通信后反复切换任务 | 返航锁定与明确优先级 |
| 只有动画没有验证 | 对照、消融、权重扫描、85 项测试与十套浏览器流程 |

以上为实现针对的问题，个人报告仍应记录本人实际复现和排错过程。

## 可准确表述的创新

“基于公开街区数据构建高度障碍与地上/地下交通风险分层，把风险 A*、鸟群预测和异常状态机连接为可交互、可解释、可复现的低空配送课程仿真。”

后续可加入含噪定位与感知、三维动力学、多机预约、真实交通/覆盖数据和基于返航距离的电量决策。上述尚未实现，不能作为本版本已完成贡献。


运营与跨江模块、能耗区别及固定飞层边界详见 运营与跨江说明.md。当前自动测试85项；单模块187次与三组调度9次合计196次模型试验。


无人机基准支持16机课堂展示，120–420m教学飞层；原8机实验保持120–260m。三策略按钮与runOperations的默认8机基准保持不变。课堂PPT与讲稿见最新材料，模型/定位圈按屏幕放大不修改物理碰撞半径。85项模型测试、十套浏览器流程覆盖更新。

## 当前混合交通入口

默认16架无人机、2架直升机和2架eVTOL，主屏展示实时调度记录、场站和航路占用者、候机与让行。原三策略对照仍固定8架无人机，不把20架资源规模变化归因于算法。新增6次混合试验独立保存。当前85项模型测试和十套浏览器流程的结果见results/verification.json。

## 运行流畅性

默认启用流畅画质，在实验设置中可切换为精细。多机航段复用城市环境，路径查询缓存按世界版本更新；车辆、信号灯和机体批量绘制，保留完整机队与任务。3D缩略图低频刷新，隐藏遥测不重复绘制，风险更新不重建城市几何。高倍率以流畅运行优先，设备繁忙时实际加速会低于目标倍率。详细测量见docs/流畅性优化说明.md及results/performance-profile.json。

当前实时默认模式包含地面/10m教学平台起降、柜点交接、消防机地面预留与返场降落。原固定巡航实验仍保留，参数与时间不混用；详见地面起降与消防响应.md。
