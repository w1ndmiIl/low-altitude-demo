# 一屏课堂演示

主屏按1280×720、1366×650、1366×768、1920×1080浏览器视口验证。桌面首屏集中显示城市画面、任务状态、事件进度与操作，手机保留可滚动的紧凑布局。

## 信息布局

- 顶部：模式、选中飞机、2D/3D、镜头、隧道剖视和主屏全屏。
- 全局指标：仿真时间、任务中机队数量、日常/应急完成、等待和抢占。
- 主画面：黄色选中标记与剩余航路，蓝灰已飞轨迹，橙色事件位置和蓝色地面接应标记。
- 右侧：真实任务阶段、现场服务剩余计时、电量、链路、重规划与净距。事件选择器可切换已发生的案例。
- 下方操作：开始/暂停、速度、日常需求、应急任务、鸟群/阵风/导航等注入。
- 页面下部：折叠的参数、完整日志、机队、调度对照和单模块实验。

## 建议现场顺序

1. 默认20架混合机队、两岸全景、手动发布事件。点击开始，观察取件和飞行阶段。事件讲解可用1×或2×。
2. 发布楼宇火情。默认自动聚焦事件和响应飞机，查看抢占次数、任务优先级、服务倒数与强度指标。
3. 发布跨江急送。地图显示接应车辆标记，右侧分别显示空中投放、地面接应及最终交接。完整任务可以16×或32×观察。
4. 地面先到仍会等待空中投放，空中到位也不等于服务结束。完成后耗时冻结。
5. 选择正在飞行的无人机，注入鸟群或导航异常。查看重规划或悬停状态，观察已飞和剩余航路的区别。
6. 切换单模块。场景和算法选择直接出现在主屏，比较风险/距离路线，演示失联、返航或不可达。单模块指标改为航程、代理暴露和配送结果。

自动剧本仍按30/45/60/90模拟秒触发。建议从0秒重置后启用，便于按顺序讲解。关闭“新事件自动聚焦”可保持手动镜头，使用“聚焦事件”主动定位。

“主屏全屏”包括指标、画面、侧栏和操作。Esc或再次点击按钮退出。镜头、事件回看和选机不重置任务时间。参数和完整实验为次要信息，可退出全屏后展开。

## 模型与显示边界

所有进度从任务、事件、心跳及服务状态读取，不使用预设成功动画或虚构飞行百分比。多机中的“当前航段到位”与整个任务完成分开。火情强度是教学指标，医疗是物资任务，模型放大不修改物理半径。

渲染优化包括按需生成3D风险纹理、减少轨迹几何重建、复用静止服务效果、释放独占材质以及保留公共材质。调度、地图、能耗和固定8机实验条件保持原实现。

验证：85项模型测试，加审计回归、混合交通、一屏、机队交互、相机/触摸、运营、单模块导出十套浏览器流程。源码为demo/stage-model.js、stage.css及相应界面/渲染模块。

## 当前混合交通入口

默认16架无人机、2架直升机和2架eVTOL，主屏展示实时调度记录、场站和航路占用者、候机与让行。原三策略对照仍固定8架无人机，不把20架资源规模变化归因于算法。新增6次混合试验独立保存。当前85项模型测试和十套浏览器流程的结果见results/verification.json。

## 运行流畅性

默认启用流畅画质，在实验设置中可切换为精细。多机航段复用城市环境，路径查询缓存按世界版本更新；车辆、信号灯和机体批量绘制，保留完整机队与任务。3D缩略图低频刷新，隐藏遥测不重复绘制，风险更新不重建城市几何。高倍率以流畅运行优先，设备繁忙时实际加速会低于目标倍率。详细测量见docs/流畅性优化说明.md及results/performance-profile.json。

当前实时默认模式包含地面/10m教学平台起降、柜点交接、消防机地面预留与返场降落。原固定巡航实验仍保留，参数与时间不混用；详见地面起降与消防响应.md。
